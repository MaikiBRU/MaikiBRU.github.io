# StockARG

Sistema de gestion de stock, ventas y clientes enfocado en datos confiables y flujos claros.

## Objetivo
Centralizar productos, clientes, ventas y movimientos de stock en un solo lugar para reducir errores operativos.

## Stack
- Python
- Tkinter
- MySQL

## Modulos principales
- Login
- Clientes
- Proveedores
- Productos
- Ventas
- Movimientos de stock
- Reportes (CSV/PDF)

## Modelo de datos (resumen)
- Clientes
- Proveedores
- Productos
- Ventas
- DetalleVenta
- MovimientosStock
- Usuarios

## Reglas de integridad (ejemplos)
- No permitir venta con stock insuficiente
- Evitar duplicados de productos
- Validar cantidades y precios

## Arquitectura
- UI (Tkinter)
- Logica de negocio
- Persistencia (MySQL)
